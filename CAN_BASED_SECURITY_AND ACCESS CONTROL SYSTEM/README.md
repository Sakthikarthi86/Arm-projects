In this project, CAN is used for security and access control. The system consists of three nodes: one transmitting node and two receiving nodes. The transmitting node detects the user using an RFID module and broadcasts the user ID over the CAN bus. One receiving node controls the gate; if the user ID is valid, the gate opens automatically, and if the user ID is invalid, an alarm is triggered. The second receiving node displays whether the user ID is valid or invalid based on the received CAN message.
